# Caryophyllales Medullary Bundles DatasetThis taxon-specific dataset documents the occurrence of medullary bundles across Caryophyllales.The dataset is maintained in a dedicated repository to support independent development, collaborative authorship, and versioned releases.GitHub repository  https://github.com/ilcneto/caryophyllales-medullary-bundles-datasetZenodo archive  https://zenodo.org/records/22849823This dataset is part of the **Plant Vascular Variants Database**, which integrates global and taxon-specific datasets documenting vascular variants across seed plants.
